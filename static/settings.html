Science English设置

每日学习安排

改完点“保存”。已入库的低档词请由管理员在服务器执行重筛命令后移除。

句子参考译文（可选）

填写后，句子练习页会出现“查看参考译文”按钮。Key 保存在服务器的 SQLite 里。

🤖 AI 检索（可选）

填入任意 OpenAI 兼容接口的 Key 后，「文献库」页的 AI 检索并入库 就能： 根据你填写的领域关键词自动生成一组学术检索词（含同义/近义表达）+ 推荐该领域期刊名，然后自动抓取入库。 不填 Key 时该按钮退化为“用你填的关键词直接抓取”。Key 只保存在本机数据库。

文献抓取

每批自动抓取开放获取文献 → 词库。可再加如 “phosphorus metabolism models”“phosphorus big data” 等你研究方向的新关键词。

📱 Android App（在线壳 v1.2）

App 打开后自动登录本系统（已内置访问凭据），无需每次输密码；网页新增功能发布到服务器后 App 自动生效，无需重装。

下载安装包 science-english-v1.2.apk
首次安装需在系统设置允许“安装未知应用”，装好后桌面出现「Science English」图标；升级直接覆盖安装即可。

命令速查（在服务器上执行）

服务状态sudo systemctl status science-english
抓取文献cd /opt/science-english && .venv/bin/python manage.py fetch && sudo .venv/bin/python manage.py extract
下载开放全文cd /opt/science-english && .venv/bin/python manage.py oa
词库概况cd /opt/science-english && .venv/bin/python manage.py status
